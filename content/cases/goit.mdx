<Case title="로그인 없는 공개 웹에서 비용과 권한 지키기">
  <Step label="상황">누구나 로그인 없이 쓰는 웹이라 서버 함수를 아무나 부를 수 있고, 한 번 부를 때마다 AI와 지도 API 비용이 듭니다.</Step>
  <Step label="구현">Claude와 카카오 키는 Supabase Edge Function 뒤에 두고, 허용한 사이트 주소에서 온 요청만 받습니다. 하루 횟수는 방문자별과 전체 합계를 DB 함수로 함께 세어, 주소가 퍼져도 하루 요금이 합계에서 멈춥니다. 방문자는 IP를 그대로 저장하지 않고 서버 키로 서명한 해시로만 구분합니다.</Step>
  <Step label="방어">사용자 글은 여행 조건으로만 읽게 지시하고, 모델의 답은 정해 둔 항목과 길이만 통과시킵니다. 공유 링크는 맞힐 수 없는 id를 쓰고 30일 뒤 만료됩니다.</Step>
</Case>

<Case title="DoIt2와 잇기: 담아 둔 곳 → 일정 → 기록">
  <Step label="고잇투 → 두잇투">일정 화면의 "두잇투에 담기"가 공유 링크를 만들고 두잇투의 웹 페이지를 엽니다. 휴대폰이면 앱을 바로 열고, 컴퓨터에서 열었으면 휴대폰으로 옮길 QR과 링크를 보여 줍니다. 앱에서는 장소마다 담을지 여행 하나로 묶을지, 어느 공간에 담을지 고르고, 출발 날짜가 있으면 목표 날짜로 들어갑니다.</Step>
  <Step label="두잇투 → 고잇투">두잇투 항목의 "고잇투로 일정 짜기"가 고른 곳을 "꼭 넣을 곳"으로 실어 고잇투를 엽니다. 서버는 그 곳을 모두 넣고 나머지를 가까운 곳으로 고르라고 모델에 전합니다.</Step>
  <Step label="권한">로그인 없이 공유 id로만 잇고, 두잇투 앱과 웹 페이지는 서버 함수에서 공유 일정 읽기만 할 수 있게 막았습니다. 배포 뒤에는 실제 요청으로 읽기는 되고 생성·저장·길찾기는 막히는지 확인했습니다.</Step>
</Case>
